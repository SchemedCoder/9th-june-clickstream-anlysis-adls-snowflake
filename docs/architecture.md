# Clickstream Analytics Platform

## Architecture Overview

The platform simulates clickstream activity generated by users browsing an e-commerce website.

The generated events are stored in Azure Data Lake Storage Gen2 and automatically ingested into Snowflake using Snowpipe.

The data then flows through a Bronze-Silver-Gold architecture for analytics and reporting.

## Bronze Layer

Purpose:

Store raw clickstream events exactly as received.

Examples:

- HOME_PAGE
- SEARCH
- PRODUCT_VIEW
- ADD_TO_CART
- CHECKOUT
- PURCHASE

No transformations are applied.

---

## Silver Layer

Purpose:

Improve data quality.

Transformations:

- Remove duplicates
- Handle null values
- Standardize event names
- Validate timestamps
- Track late-arriving events

---

## Gold Layer

Purpose:

Business-ready analytics.

Outputs:

### Session Analytics

- Session Duration
- Page Views
- Product Views

### Product Analytics

- Product Views
- Cart Adds
- Purchases

### Funnel Analytics

- Homepage Visits
- Searches
- Product Views
- Add To Cart
- Checkout
- Purchases

---

## Snowflake Components

### External Stage

Reads files directly from ADLS Gen2.

### Snowpipe

Automatically loads new files into Bronze tables.

### Streams

Tracks changes in Bronze tables.

### Tasks

Automates Bronze → Silver → Gold processing.

---

## Business KPIs

### Conversion Rate

Purchases ÷ Visits

### Cart Abandonment Rate

Add To Cart − Purchases

### Average Session Duration

Session End Time − Session Start Time

### Top Products

Products with highest purchases

### Most Active Users

Users with highest session counts
